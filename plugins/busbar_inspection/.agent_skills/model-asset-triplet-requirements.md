# Model Asset Triplet Requirements

给后续插件代理复用的最小资产补齐顺序：

1. ONNX 不是单文件资产，至少要同时具备 `onnx + manifest + class_map`。
2. 没有真实训练源时，不要伪造三件套。
3. 旧 ONNX 若无法追溯到真实类别、输入尺寸、输出格式和导出来源，不得安全复用。
4. 资产补齐先于替代资格判定。
5. 替代资格判定先于默认路径切换。

停止条件：

- 没有真实权重或导出来源时，停止。
- 无法确定类别集合、输入尺寸或输出格式时，停止。
- 只能靠猜测填写 manifest/class_map 时，停止。
- 资产三件套尚未自洽时，不要推进默认链切换。
