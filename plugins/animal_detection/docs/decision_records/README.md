# Decision Records

本目录存放 Architecture Decision Records (ADR)。

当前决策记录已整合到 `../design_notes/README.md` 中（DR-001 ~ DR-009）。

后续独立的重大架构决策（如模型更换、检测流水线重构、SDK 升级适配）在此目录以独立文件记录：

```
NNNN-title.md
```

模板：
```markdown
# NNNN: 标题

## 状态
Proposed / Accepted / Deprecated

## 上下文
做出决策的背景

## 决定
具体选择了什么

## 后果
正面和负面影响
```
