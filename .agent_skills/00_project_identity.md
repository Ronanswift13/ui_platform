# 00 — 项目身份与边界

## 身份

- **正式名**: 输变电激光星芒破夜绘明监测平台
- **代号**: DarkBreaker / 破夜绘明
- **包名**: powerstation-monitor
- **版本**: 3.0.0
- **许可**: Proprietary

## 业务域

为输变电站提供 AI 驱动的自主巡视与监测，覆盖:
- 室外设备巡视 (主变/开关/母线/电容器/表计/鸟类)
- 室内监测 (电子围栏/气体/声学)
- 多模态融合 (可见光 + 热成像 + 声学 + 气体 + 高光谱)
- 深度学习推理 (YOLOv8-ViT / GL-TransLSTM / CNN-LSTM / DeepSORT)

## 边界

| 属于本项目 | 不属于本项目 |
|---|---|
| 站内 AI 巡视全链路 | 电网调度 / SCADA 核心 |
| 插件化算法集成 | 模型训练集群管理 |
| 证据链 + 回放 | 长期数据湖 / 数仓 |
| Web 监控仪表盘 | 移动端 App |
